============================================================

JointPDEffortController

command interface:
  joint_i/effort

state interfaces:
  joint_i/position
  joint_i/velocity
  
Control law:

τ_i = Kp_i(q_des − q) + Kd_i(dq_des − dq)

Initial state:
q̇d = 0
qd = initial joint position
>> So it behaves as a hold-position effort controller.
