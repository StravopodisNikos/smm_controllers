Design: One plugin class per controller type

smm_controllers/JointPDController
smm_controllers/GravityCompensationController
smm_controllers/PDGravityController
smm_controllers/InverseDynamicsController
smm_controllers/CartesianImpedanceController

This is most user-friendly because users can load controllers like normal ROS 2 controllers!

Use shared lib! One internal shared library for common functionality!

smm_controller_core

contains:

joint-name loading
state-interface extraction
command-interface writing
parameter validation
dynamics object creation from smm_screws
safety clamps
matrix/vector helpers

Separate plugin library per family!

libsmm_joint_space_controllers.so
libsmm_task_space_controllers.so

It matches ROS 2 community expectations:
one controller = one plugin
configured by YAML
loaded by controller_manager
reusable in Gazebo and hardware
