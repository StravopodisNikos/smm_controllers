τ = M(q) [q̈d + Kd(q̇d − q̇) + Kp(qd − q)] + C(q,q̇) q̇ + G(q)

Steps for ros2 implementation:

1. Extend SmmDynamicsAdapter:
   computeJointDynamics(q, qdot, M, C, G)

2. Add InverseDynamicsJointController plugin

3. Add it to plugin XML + CMake

4. Add controller_type:=joint_inverse_dynamics to the generator

5. Test in Gazebo with q_des = fixed target
